# مدیریت فروشگاه — پروژهٔ اندروید (آفلاین)

این پوشه یک پروژهٔ کامل Android Studio / Gradle است. برنامهٔ وب شما (`app/src/main/assets/www/`) بدون هیچ تغییری در منطق داخل یک WebView آفلاین اجرا می‌شود (بدون اینترنت). فایل‌های `index.html`، `app.js` و `style.css` همان نسخه‌ای هستند که آزمون شده‌اند (۳۲ آزمون حسابداری، ۱۹ داشبورد و فروش، ۲۰ قابلیت‌های جدید، ۷ صفحه‌ها).

## ساخت APK
1. Android Studio (Koala یا جدیدتر) → Open → همین پوشه. بگذارید Gradle Sync کامل شود (اینترنت لازم است).
2. Build → Build APK(s). خروجی: `app/build/outputs/apk/debug/app-debug.apk`
3. یا با خط فرمان (JDK 17+ و Android SDK 34): `gradle wrapper --gradle-version 8.7` سپس `./gradlew assembleDebug`
4. برای انتشار: Build → Generate Signed Bundle / APK و کلید امضا را **جایی امن نگه دارید**؛ با گم شدن آن، به‌روزرسانی ممکن نیست.

## فونت وزیرمتن
دو فایل `Vazirmatn-Regular.woff2` و `Vazirmatn-Bold.woff2` را در `app/src/main/assets/www/fonts/` بگذارید (مجوز OFL، قابل بسته‌بندی). `@font-face` در `style.css` آماده است. بدون این فایل‌ها برنامه با Tahoma درست کار می‌کند.

## پل‌های اندروید (در MainActivity.java)
`AndroidBridge.saveFile` (پشتیبان JSON/CSV در پوشهٔ Download)، `shareFile` (اشتراک فایل/فاکتور)، `printPage` (چاپ و PDF)، همچنین پنجره‌های تأیید/هشدار، انتخاب فایل برای ورود اطلاعات، لینک‌های واتس‌اپ/تلگرام/پیامک و دکمهٔ برگشت.

## هشدار دادهٔ کاربر
اطلاعات در IndexedDB همین برنامه ذخیره می‌شود. با حذف برنامه یا «پاک کردن داده‌ها» از بین می‌رود. پشتیبان‌گیری منظم JSON ضروری است. نصب نسخهٔ جدید روی نسخهٔ قبلی (با همان کلید امضا) اطلاعات را نگه می‌دارد.

## قابلیت‌های تازه
- **فروش سریع گرمی:** مقدار دلخواه، دکمه‌های +۵/+۱۰/+۲۰/+۵۰/+۱۰۰ گرم و جمع هر ردیف.
- **پشتیبان:** نوار هشدار روی داشبورد؛ در اندروید هنگام رفتن برنامه به پس‌زمینه، حداکثر روزی یک پشتیبان خودکار در Download ذخیره می‌شود.
- **قفل برنامه:** «بیشتر ← قفل برنامه». رمز ۴ تا ۶ رقمی (فقط هش، روی همین دستگاه) و اثر انگشت (BiometricPrompt؛ نیاز به `androidx.biometric` که در build.gradle هست).
