# ساخت APK فروشگاه حنا با GitHub Actions

این پروژه برای ساخت آنلاین APK آماده شده است. کد اصلی برنامه بازنویسی نشده؛ فایل `app.js` همان نسخه موجود در پروژه است و `style.css` با نسخه CSS همراه فایل‌های اخیر شما هماهنگ شده است. فایل‌های تست نیز نگه داشته شده‌اند.

## روش استفاده با موبایل

1. وارد https://github.com شوید و حساب بسازید یا وارد حساب خود شوید.
2. از علامت `+` گزینه `New repository` را بزنید.
3. نامی مثل `HanaShop-android` وارد کنید، گزینه `Private` را انتخاب کنید و `Create repository` را بزنید.
4. در مخزن جدید، `Add file` → `Upload files` را بزنید.
5. محتویات این پوشه را بارگذاری کنید؛ خود پوشه‌ی `HanaShop` را دوباره توی یک پوشه‌ی تو در تو قرار ندهید. فایل `build.gradle` باید در ریشه مخزن دیده شود و پوشه‌های `.github` و `app` هم کنار آن باشند.
6. روی `Commit changes` بزنید.
7. وارد تب `Actions` شوید. اگر GitHub درخواست فعال‌کردن Actions کرد، آن را فعال کنید.
8. اجرای `Build HanaShop APK` را باز کنید. با هر بار بارگذاری/ثبت تغییر روی شاخه `main` یا `master` نیز فرایند اجرا می‌شود. برای اجرای دستی: `Actions` → `Build HanaShop APK` → `Run workflow`.
9. صبر کنید تا مراحل تست و ساخت تمام شوند. وضعیت سبز یعنی مراحل خودکار با موفقیت انجام شده‌اند؛ اگر قرمز شد، وارد همان اجرا شوید و اولین مرحله قرمز را باز کنید تا خطا دیده شود.
10. پایین صفحه اجرای موفق، بخش `Artifacts` را پیدا کنید و `HanaShop-debug-APK` را دانلود کنید. ZIP دانلودشده را باز کنید تا `app-debug.apk` را بگیرید.
11. فایل APK را به گوشی منتقل و نصب کنید. اندروید ممکن است اجازه‌ی نصب از آن مرورگر/مدیر فایل را بخواهد.

## نکات مهم

- فایل خروجی `debug APK` برای نصب و آزمایش است، نه نسخه نهایی انتشار فروشگاهی.
- این گردش‌کار APK می‌سازد و سه مجموعه آزمون JavaScript را اجرا می‌کند؛ آزمون کامل روی گوشی واقعی، چاپ، انتخاب فایل، اثر انگشت، ذخیره در Downloads و بازیابی پشتیبان همچنان باید دستی انجام شود.
- APK دیباگ با کلید دیباگ خودکار امضا می‌شود. برای به‌روزرسانی‌های پایدار باید کلید امضای release را امن نگه دارید؛ کلید خصوصی را هرگز در مخزن GitHub قرار ندهید.
- اطلاعات فروشگاه در حافظه محلی برنامه/IndexedDB نگه‌داری می‌شود. قبل از حذف برنامه یا پاک‌کردن داده‌ها پشتیبان بگیرید.
- فایل `gradle-wrapper.jar` در پروژه اولیه موجود نبود؛ گردش‌کار فعلی از Gradle نصب‌شده روی runner استفاده می‌کند، بنابراین برای ساخت آنلاین به آن فایل وابسته نیست.
- هیچ رمز، کلید امضا یا داده واقعی مشتری را در مخزن قرار ندهید.
